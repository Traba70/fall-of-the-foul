# Fall of the Foul

A dark-fantasy arena ARPG for mobile, inspired by **Elden Ring** and **Overgeared Hero**.
Slay wave after wave of the foul, gather souls, forge your build across three classes,
and topple five bosses. Difficulty scales forever.

### ▶ Play / Install
**https://traba70.github.io/fall-of-the-foul/**

- **Android (Chrome):** open the link → menu **⋮** → **Install app** / **Add to Home screen**.
- **iPhone (Safari):** open the link → **Share** → **Add to Home Screen**.

It's an installable **PWA**: it launches fullscreen like a native app, works **offline**
after the first load, and **saves your progress on the device**.

### 🎮 Controls
Drag on the left half of the screen to move; tap **Attack**, **Skill**, **Dodge**.
On desktop: **WASD** to move, **J** attack, **K** skill, **L / Space** dodge, **Esc** pause.

### 🕹 What's inside
- Overgeared-style menu: **Gear**, **Fight**, **Level Up**
- Six-stat gear system (Strength, Mana, Magic, Defense, Vitality, Luck), armor **set bonuses**,
  per-item buffs, ring & weapon slots, upgrades to Lv 99
- Three classes — **Melee / Ranger / Mage** — with swappable weapon skills & spells
- Top-down arena, 5 enemy types across 3 ranks, wave spawns, **5 unique bosses**
- All art drawn procedurally in code — no external images; no network calls during play

### 🛠 Tech
Vanilla HTML/CSS/JS, Canvas 2D, a web-app manifest + service worker for offline install,
and `localStorage` for saves. Static files only — host anywhere.
